# Прогноз направления дневной доходности акций IMOEX

**Новости Telegram (ruBERT) + динамический граф эмитентов + Neural Sheaf Diffusion**

Курсовая работа · экономический факультет МГУ им. М. В. Ломоносова · Корякин Даниил · 2025–2026

---

## Коротко

End-to-end пайплайн: 46 бумаг индекса IMOEX с августа 2022 по декабрь 2025, 22 тыс. новостей
из трёх Telegram-каналов, привязанных к эмитентам и векторизованных ruBERT, динамический
знаковый граф корреляций и графовая модель на аппарате клеточных пучков (Neural Sheaf
Diffusion, Bodnar et al., 2022). Сравнение с пятью бейзлайнами на walk-forward валидации
(четыре фолда, пять сидов, равный бюджет оптимизации у всех архитектур), тесты значимости
и бэктест.

| Модель | MCC (4 фолда × 5 сидов) |
|---|---:|
| LSTM, только цены | **+0,073 ± 0,013** |
| GAT / GCN / NSD / MLP | +0,009 / +0,008 / +0,008 / +0,007 |
| NSD без новостей | +0,027 ± 0,017 |

Результат отрицательный и воспроизводимый: на однодневном горизонте ни граф, ни новости не
дают сигнала сверх того, что уже есть в ценах. Единственный устойчивый эффект:
предсказуемость знака доходности по 20-дневному окну цен, и он не переживает транзакционных
издержек. Весь анализ умещается в четыре ноутбука и воспроизводится на CPU побитово
за 20 минут.

## Задача

Трёхклассовая классификация знака доходности акции на следующий торговый день:
`DOWN` / `FLAT` / `UP` по терцилям, рассчитанным для каждого тикера на train-части фолда.
Метрика: MCC, коэффициент корреляции Мэтьюса. При почти равных классах accuracy не различает
модели, а MCC равен нулю для любого вырожденного предсказания.

Три гипотезы:

* **H1**: sheaf-структура на знаковом графе даёт прирост над GCN и GAT;
* **H2**: ruBERT-эмбеддинги новостей улучшают прогноз;
* **H3**: стратегия long-only top-10 на сигналах модели обыгрывает пассивный портфель.

## Модель и бейзлайны

Sheaf-диффузия заменяет скалярный вес ребра парой матриц `d × d`: сообщение по ребру
`F_{v◁e}ᵀ (F_{v◁e} h_v − F_{u◁e} h_u)` с двумя разными отображениями ограничения на ребро даёт
знаконеопределённый оператор, который может учиться на отрицательных связях, где GCN
только сглаживает. Архитектура: `Linear(775 → 64)` → два слоя диффузии (`d = 4`, обучаемый
шаг `α`) → `Linear(64 → 3)`, 68 965 параметров.

Бейзлайны на тех же фолдах: GCN и GAT на тех же признаках и графе, MLP на тех же признаках
без графа, LSTM на 20-дневном окне цен без новостей и графа, мажоритарный класс. Все модели
обучаются одним циклом: батч из 10 торговых дней, склеенных в один несвязный граф, AdamW,
early stopping по валидационному MCC. У всех архитектур одинаковое число шагов оптимизатора.

Валидация: walk-forward по месяцам, сетка 18/6/6 с шагом 3, четыре фолда с шестимесячными
тестовыми окнами (с октября 2024 по декабрь 2025), пять сидов на конфигурацию. Оценка: медиана
по сидам внутри фолда, среднее ± отклонение по фолдам.

## Результаты

### Модели

| Модель | MCC | по фолдам | IC | Macro-F1 |
|---|---:|---:|---:|---:|
| LSTM (только цены) | **+0,073 ± 0,013** | +0,059 … +0,091 | +0,022 | 0,368 |
| GAT | +0,009 ± 0,018 | −0,013 … +0,026 | +0,004 | 0,317 |
| GCN | +0,008 ± 0,027 | −0,027 … +0,031 | +0,004 | 0,325 |
| NSD | +0,008 ± 0,024 | −0,018 … +0,037 | −0,005 | 0,324 |
| MLP | +0,007 ± 0,019 | −0,012 … +0,028 | +0,012 | 0,324 |
| Majority | 0,000 | | | 0,162 |

<p align="center"><img src="figures/mcc_by_fold.png" width="760" alt="MCC по фолдам"></p>

NSD, GCN, GAT и MLP неотличимы ни от нуля, ни друг от друга (парный t-тест по фолдам
p ≈ 0,9; тест Диболда-Мариано меняет знак от сида к сиду). LSTM значимо лучше NSD
(p = 0,010), и только у LSTM тест Пезарана-Тиммерманна даёт согласованный по всем сидам
направленный сигнал для обоих классов.

### Абляция NSD

| Конфигурация | MCC | по фолдам |
|---|---:|---:|
| **без новостей** | **+0,027 ± 0,017** | +0,012 … +0,050 |
| базовая (d = 4, L = 2, corr-MST, с новостями) | +0,008 ± 0,024 | −0,018 … +0,037 |
| L = 1 / L = 3 | +0,007 / +0,009 | |
| d = 2 / d = 6 | +0,003 / +0,005 | |
| секторный граф | −0,010 ± 0,014 | −0,024 … +0,002 |

Отключение новостей улучшает NSD на всех четырёх фолдах (p = 0,38 при n = 4, то есть незначимо, но
знак противоположен H2). Гиперпараметры стебля и глубины ничего не меняют.

### Бэктест

Long equal-weight из десяти бумаг с наибольшим `P(UP) − P(DOWN)`, дневная ребалансировка.
Бенчмарк: равновзвешенный портфель всех 46 бумаг; тесты на двух непересекающихся парах
фолдов, медиана по сидам, без издержек.

| Пара фолдов | NSD top-10 | LSTM top-10 | NSD без новостей | равновзвешенный |
|---|---:|---:|---:|---:|
| A: 2024-10 … 2025-09 | −5,1 % | −10,9 % | +1,7 % | −5,9 % |
| B: 2025-01 … 2025-12 | −9,2 % | −2,9 % | +3,6 % | −2,1 % |

<p align="center"><img src="figures/backtest.png" width="820" alt="Кумулятивная доходность"></p>

Ни одна модель не обыгрывает бенчмарк на обеих парах; лучший MCC у LSTM даёт худшую
доходность. Оборот 70–75 % портфеля в день: при 5 б.п. round-trip все конфигурации в минусе.

### Чувствительность к сетке валидации

NSD на контрольной сетке из двух длинных фолдов (24/6/6, шаг 6) даёт +0,022 при разбросе
по сидам от +0,005 до +0,063; на четырёх фолдах +0,008. Разброс по сидам внутри одного
фолда втрое больше разницы между графовыми моделями: оценка по одному сиду и двум фолдам
могла бы показать любое значение из этого диапазона. Отсюда протокол: медиана по пяти сидам,
среднее по четырём фолдам, парные тесты по фолдам.

## Выводы

| | Гипотеза | Статус |
|---|---|---|
| H1 | sheaf-структура даёт прирост над GCN/GAT | не подтверждается: разница 0,001 MCC |
| H2 | новости улучшают прогноз | не подтверждается: без новостей лучше |
| H3 | стратегия обыгрывает пассивный портфель | не подтверждается |

Что из этого следует. Потолок задачи определяет сигнал в данных, а не архитектура: ни
пучковый оператор, ни перебор гиперпараметров не сдвигают MCC графовых моделей от нуля.
Новости в текущей привязке работают как общерыночный индикатор с 90 % широковещательных связей и не
различают бумаги. Направления, которые имеют смысл: горизонт таргета в 5–20 дней (чтобы
сигнал переживал издержки), рост доли явных привязок новостей (NER вместо словаря),
динамический состав индекса и история с 2018 года.

## Структура репозитория

```
00_build_data.ipynb   сбор и подготовка данных: MOEX ISS, Telegram, привязка, ruBERT, признаки, граф → data/
01_data.ipynb         профиль данных и графа → figures/
02_experiments.ipynb  модели, walk-forward CV, 250 прогонов → results/
03_results.ipynb      таблицы, тесты значимости, бэктест → results/, figures/
figures/              графики из этого README
requirements.txt      зависимости
```

Папки `data/` и `results/` создаются ноутбуками локально и в репозиторий не входят: сырые
данные весят сотни мегабайт, а метрики и предсказания пересчитываются из них.

## Воспроизведение

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/jupyter nbconvert --to notebook --execute --inplace 00_build_data.ipynb   # данные: сеть, Telegram API, GPU для ruBERT
.venv/bin/jupyter nbconvert --to notebook --execute --inplace 02_experiments.ipynb  # ≈ 20 мин на CPU
.venv/bin/jupyter nbconvert --to notebook --execute --inplace 03_results.ipynb
```

Ноутбук 00 собирает `data/` с нуля: котировки с MOEX ISS без ключей, новости через Telegram API
(переменные `TELEGRAM_API_ID`, `TELEGRAM_API_HASH`, `TELEGRAM_PHONE` в файле `.env`), эмбеддинги
ruBERT лучше считать на GPU/MPS. Состав индекса и новостной корпус зависят от момента выгрузки,
поэтому при пересборе данных числа могут отличаться от приведённых. Обучение в 02 идёт на CPU
в один поток и при одинаковых данных воспроизводится побитово.
